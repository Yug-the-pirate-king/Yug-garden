## Quick Start / Local Development

Open `index.html` directly in your browser or run a lightweight local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Navigate to `http://localhost:8000` to view the site locally.
