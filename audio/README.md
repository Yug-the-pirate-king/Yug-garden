# Audio & Music Player Folder

Welcome to your portfolio's interactive music player folder!

### How to add your music & thumbnails:
1. **Audio Tracks**: Drop any `.mp3`, `.wav`, or `.ogg` audio files into this folder.
   - For example: `track.mp3` or `song.mp3`.
   - The player automatically looks for `audio/track.mp3` or any audio files listed in the player playlist.
2. **Cover Thumbnail**: Drop an image file here named `cover.jpg`, `cover.png`, or `cover.webp` (ideal size: 500x500 square).
   - If no custom thumbnail is provided, the player automatically displays the **Default Celestial Botanical Vinyl** theme matching your Type Garden color palette!
3. **Fallback & Web Audio**:
   - If no audio file has been dropped in yet, the player includes a built-in soothing Web Audio ambient botanical melody so it plays immediately when clicked!
