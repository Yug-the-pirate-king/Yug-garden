# Yug Shah - Portfolio & TypeGarden

Personal portfolio and interactive web experience for **Yug Shah** (Shah Yug Vipulbhai) — Computer Science and Engineering developer, researcher, and builder based in Mumbai.

Live Website: [https://yugshah.xyz](https://yugshah.xyz)

## Features

- **Interactive Canvas & Creative Visuals**: Built with custom HTML5 Canvas rendering for dynamic visuals and creative coding experiments.
- **Audio & Ambient Controls**: Integrated interactive audio playback and volume controls.
- **Responsive & Accessible Design**: Optimized for desktop, tablet, and mobile viewing with sleek dark-mode glassmorphic styling.
- **Comprehensive SEO & Structured Data**: Google Knowledge Graph Schema (JSON-LD), OpenGraph protocol, and XML sitemaps for maximum visibility.
- **Fast & Dependency-Free**: Pure HTML5, CSS3, and modern Vanilla JavaScript with zero heavy build steps.

## Quick Start / Local Development

Open `index.html` directly in your browser or run a lightweight local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Navigate to `http://localhost:8000` to view the site locally.
