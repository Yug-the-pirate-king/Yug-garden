02 // Flagship Case Study

Hatcha — Generative UI Engine

An event planner that dynamically reconstructs its user interface around real-time context. Shipped at Google I/O 2026.

Google I/O 2026 Innovation Track

Stopping Static Flows. Composing Generative Interfaces.

Traditional event apps suffer from combinatorial flow explosion: every new event type introduces divergent forms and dead ends. With Hatcha, we architected a GenUI shell: a deterministic outer boundary that hosts LLM-composed micro-widgets on the fly — adjusting theme palette, card density, and action priorities dynamically.
